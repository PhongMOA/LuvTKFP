# LuvTKFP — FinPlan

Ứng dụng quản lý tài chính cá nhân và lập kế hoạch cuộc sống theo phong cách RPG.

## Tính năng

- 💰 Quản lý thu chi, ví tiền, ngân sách
- 📊 Báo cáo tài chính theo tháng
- ✅ Nhiệm vụ hàng ngày / tuần / tháng với hệ thống streak
- 🎮 Hệ thống level, EXP, chỉ số nhân vật (STR/DEX/INT/CON/CHA)
- 🔔 Thông báo trong app
- 🔒 Bảo mật PIN / sinh trắc học
- 🔄 Tự động kiểm tra và thông báo cập nhật mới
